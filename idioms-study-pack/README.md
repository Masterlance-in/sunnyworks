# Ten English Idioms — Study Pack

A visual memory sheet and a companion guide for the ten idioms supplied in the conversation.

## Files

- [Illustrated study sheet, full resolution (PNG)](idioms-illustrated-study-sheet.png) — ten numbered scenes, in the same order as this guide.
- [Compact illustrated sheet (JPG)](idioms-illustrated-study-sheet.jpg) — same image in a smaller format for web sharing.
- [Idioms guide](idioms-guide.md) — meanings, Hindi glosses, examples, memory hooks, and cautious origin notes.

## How to use

Look at a numbered scene, cover the matching entry in the guide, and recall its meaning. The image is a memory aid; the origin notes distinguish documented history from a helpful visual association.

## Accuracy note

An idiom's memorable image can explain why its meaning makes sense without proving where the expression historically began. Where a firm origin is not documented, the guide says so.
